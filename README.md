## This portfolio

Rebuilt in Oct 2026 from Next.js 16 to Astro 7 + Tailwind CSS 4. Zero runtime JavaScript. Cinematic scrollytelling homepage with 7 chapters, CSS scroll-driven animations, film grain, and full SEO (OG PNGs, RSS, sitemap, JSON-LD).

```bash
npm install
npm run dev      # http://localhost:4321
npm run build
npm run typecheck
```

Hosted on Vercel. `vercel.json` handles the apex → www redirect and cache headers.
